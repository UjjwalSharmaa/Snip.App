Snip ✂️

A full-stack URL shortener that turns long links into short, shareable ones and redirects visitors to the original URL.

Features
Shorten any long URL into a compact link
Redirect short links to the original destination
Clean, responsive frontend built with React and Vite
REST API backend built with Node.js
Tech Stack

Frontend: React, Vite
Backend: Node.js, Express
Database: MongoDB
